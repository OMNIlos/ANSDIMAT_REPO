## Продуктовый контекст

Мобильное приложение для обработки опытно-фильтрационных работ (откачек) в поле.
Кроссплатформенное (Android + iOS + web), двуязычное (RU/EN), бесплатная версия
с возможностью апгрейда до коммерческой. Два модуля: «Обработка откачек» и «Калькулятор»,
плюс «Полевой дневник» и «Примеры и видео».

## Технологический стек (без изменений)

- Expo SDK 53, React Native 0.79, React 19
- react-native-paper (MD3) + кастомная тема (бордовый #72002F, синий #031888)
- React Navigation (drawer + stack)
- AsyncStorage для проектов, i18n-js для локализации
- Web: Metro bundler (`web.bundler: "metro"` — исправлено, был сломан webpack-путь)

## Дизайн-система (по артборду)

- Основной цвет: бордовый #72002F; фон светлый #FFFFFF / тёмный #121212
- Шапка экрана: бордовая, слева лого-«кардиограмма» + « : Название экрана»
- Плавающее нижнее меню: скруглённый бордовый бар с 4 пунктами
  «Главная | Настройки | Справка | Выход», не перекрывает системную навигацию
  (safe-area, отступ от края), шрифт уменьшен, чтобы «Настройки» помещалось в одну строку
- Карточки: скруглённые 12–16px, светло-серые поверхности

### 3. Нижнее меню (новый компонент BottomMenuBar)
- Пункты: Главная (навигация Home), Настройки (Settings), Справка (Examples/О программе),
  Выход (Android — BackHandler.exitApp(); iOS/web — пункт скрыт, Apple запрещает
  программный выход)
- Позиционирование: absolute bottom + insets.bottom, скругление 24, высота ~64
- Шрифт подписей 11–12px — «Настройки» в одну строку — п.4.4
- Не перекрывает системные кнопки Android — п.4.5

### 4. Модуль «Обработка откачек» — главный экран (п.5, image9)
- Большая бордовая кнопка «+ Создать журнал откачки» с подписью
  «Мастер создания нового журнала обработки откачки за 3 шага» → визард
  (поля имени/типа переносятся в шаг 0 визарда как на артборде: тип ОФР + название → Создать)
- Секция «Последние проекты» (3 последних) + ссылка «Загрузить проект» справа сверху
- Карточка проекта, две зоны:
  - слева: иконка-капля, имя скважины (усечение по длине), «дата | тип опробования»,
    строка действий: звезда (избранное) + экспорт
  - справа: две кнопки-зоны «Журнал ›» (редактор замеров визарда) и «Обработка ›»
    (экран графиков DataProcessing)
- Внизу «все проекты ∨» → экран всех проектов (полный список с удалением)
- Инфо-карточка о модуле внизу
- Убран дублирующий функционал (блок «Инструменты» старого экрана)

### 5. Визард (3 шага, артборд экраны 4–7)
- Шаг 0 (создание): «Заполнить журнал и обработать ОФР»: выбор типа ОФР
  (Откачка/восстановление, Экспресс-опробование, Налив в зону аэрации, Пакеры),
  название проекта → «Создать»
- Шаг 1 «Основные параметры»: тип пласта (напорный / с перетеканием), имя опытной
  скважины, расход + размерность (м³/сут | м³/ч | л/с), мощность водоносного горизонта;
  текст-подсказка под формой
- Шаг 2 «Журнал наблюдений за уровнями»: дата начала откачки и восстановления
  (календарь), список скважин (опытная + наблюдательные), для каждой — ввод замеров
  «откачка/налив» и «восстановление» (таблица: №, время [мин/ч/сут или дата-время],
  понижение, м; «+ Добавить замер»); «+ Добавить наблюдательную скважину»
- Шаг 3 «Расстояния между скважинами, м»: расстояние от опытной до наблюдательных
  (для одиночной — радиус скважины) → «Готово» (сохранение проекта)
- Кнопки навигации «‹ Шаг N» / «Шаг N ›» внизу каждого шага, подсказки под формой

### 6. Темы
