# План переноса веб-калькуляторов в раздел «Калькулятор»

Спецификация: `docs/superpowers/specs/2026-08-20-calculator-web-port-design.md`

**Цель.** Перенести расчётную логику и динамические иллюстрации двух веб-калькуляторов
АНСДИМАТ во вкладки «Приток в котлован» и «Прогноз понижения».

**Подход.** Математика — чистыми функциями в `calc/` с jest-тестами против эталонов,
снятых с сайта. Интерфейс собирается поверх уже зелёных тестов, а не наоборот.

**Стек.** Expo / React Native 0.79, react-native-svg, react-native-paper, jest-expo.

## Общие ограничения

- Единицы пользователя из `UnitsContext`; формулы в `calc/` работают в базовых.
- Локализация ru и en, ключи в `Localization.js`.
- Палитра иллюстраций — из веба без изменений, от темы не зависит.
- Ветка `feat/field-calculator-revamp`, чужие незакоммиченные файлы не трогаем.
- Каждая задача заканчивается зелёным `npm test` и коммитом.

---

### Задача 1. Величина «площадь» в единицах

- Файлы: `calc/units.js`, `calc/__tests__/units.test.js` (если есть — дополнить)
- `QUANTITIES.AREA = 'area'`, база `m2`, варианты `m2`, `ha`, `km2`
- Тест: круговой перевод м² → га → м² сохраняет значение

### Задача 2. Справочники грунтов

- Файл: `calc/lithology.js`
- `PIT_LITHOLOGY` — 8 позиций, только `k` (глина 0.001 … гравий 80)
- `WELL_LITHOLOGY` — 10 позиций, `k`, `Sy`, `Ss`
- Тест: все `k` положительны, идентификаторы уникальны

### Задача 3. Приток в котлован

- Файлы: `calc/pitInflow.js`, `calc/__tests__/pitInflow.test.js`
- Порт `pit_calc/calc.js` целиком, включая `warnings`, `errors`, `Rvia`, `lnTerm`
- Тесты по `EXAMPLES`: четыре схемы, Q и R до 1e-4 относительной погрешности
- Отдельные тесты: r₀ по площади и по Форхгеймеру, отказ при R ≤ r₀, s > h₀

### Задача 4. Болтон

- Файлы: `calc/boulton.js`, `calc/__tests__/boulton.test.js`
- `stehfestWeights(N)`, `boultonDrawdown({ Q, k, h0, Sy, S, r, t })`
- α = 3k/(Sy·h₀), σ(p) = S + (Sy − S)·α/(p + α), N = 12
- Тесты: предельные переходы к Тейсу по S и по Sy, эталоны `boulton-A` и `boulton-B`

### Задача 5. Понижение от водозабора

- Файлы: `calc/wellDrawdown.js`, `calc/__tests__/wellDrawdown.test.js`
- `computeWellDrawdown(input)` → `{ ok, errors, warnings, sWell, sObs, formula, params,
  exceedsAllowable, dewatered }`
- `drawdownSeries(input, points)` → `[{ t, sWell, sObs }]`, лог-шкала, 30 точек
- Схемы: `theis`, `hantush`, `boulton`, `boundary`
- Граница: r_image = √(r² + 4 L_w L_p) для наблюдательной, 2 L_w для опытной
- Тесты по всем пяти наборам фикстур

### Задача 6. Разрез котлована

- Файл: `components/schemes/PitScheme.js`
- viewBox 700 × 378, палитра и геометрия из `drawScheme` в `pit_calc/app.js`
- Кривая воронки: t = ln(d/r₀)/ln(R/r₀), h = √(0.42² + (1 − 0.42²)·t)
- Тест: рендерится при пустом результате и не падает при R ≤ r₀

### Задача 7. Разрез скважин

- Файл: `components/schemes/WellScheme.js`
- viewBox 540 × 256, четыре варианта по схеме
- Уровни в стволах по рассчитанным s(r₀) и s(r)
- Тест: для каждой схемы рендерится и содержит подписи опытной и наблюдательной

### Задача 8. Графики

- Файлы: `components/charts/InflowChart.js`, `components/charts/DrawdownLogChart.js`
- По образцу `components/DepressionCone.js`
- Тест: пустой ряд не роняет компонент

### Задача 9. Разбор экрана на вкладки

- Файлы: `screens/calculator/shared.js` и шесть `screens/calculator/*Tab.js`
- `CalculatorScreen.js` остаётся каркасом с теми же шестью вкладками
- Перенос без правок логики, тесты экрана должны остаться зелёными

### Задача 10. Локализация
