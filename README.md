# АНСДИМАТ - Полевой калькулятор гидрогеолога

Мобильное приложение для гидрогеологических расчетов и анализа данных откачки скважин.

## Описание

АНСДИМАТ - это кроссплатформенное мобильное приложение, разработанное на React Native с использованием Expo. Приложение предназначено для гидрогеологов и специалистов, работающих с анализом данных откачки скважин.

### Обмен журналами: формат `.ansdimat`

Журнал ОФР выгружается в файл `.ansdimat` и открывается двойным нажатием:
приложение объявлено владельцем этого типа в обеих системах, поэтому Files,
почта, AirDrop и мессенджеры предлагают открыть файл именно в нём. Открытый
файл разворачивается в полноценный журнал — со скважинами, обеими фазами
замеров и результатами расчёта.

| Что | Где |
|---|---|
| Разбор и сборка файла | `share/projectFile.js` |
| Выгрузка и системное «Поделиться» | `share/exportProject.js` |
| Приём открытого файла | `share/incomingFile.js`, `share/ImportContext.js` |
| Диалог импорта | `components/ImportProjectDialog.js` |
| Запись в базу | `importProject` в `db/projects.js` |
| Объявление типа системе | `app.json` (iOS `UTExportedTypeDeclarations`, Android `intentFilters`) |

Файл — это JSON в UTF-8 с магической строкой, версией схемы и контрольной
суммой sha-256 от содержимого.

Числа в нём лежат в базовых единицах, а не в тех, что выбрал отправитель, и файл
объявляет это сам — блоком `units`. Ввод переводит в базовые (`toBase`), выгрузка
пишет их как есть, разбор приводит к базовым по объявленному в файле, а показ
переводит в размерности того, кто открыл журнал (`fromBase`). Поэтому геолог,
работающий в футах, откроет присланный журнал в футах, а тот же файл у коллеги
в метрах покажется в метрах — числа в базе у обоих одинаковые.

Устройство формата и принятые решения — в
[docs/superpowers/specs/2026-08-24-ansdimat-project-file-design.md](docs/superpowers/specs/2026-08-24-ansdimat-project-file-design.md).

Изменение нативной части (`app.json`) требует пересборки: `android/` и `ios/`
генерируются заново при prebuild, обновления по OTA тут недостаточно.

## Установка и запуск

### Предварительные требования

- Node.js 18+
- npm или yarn
- Expo CLI
- Android Studio / Xcode (для нативных сборок)

### Установка зависимостей

```bash
npm install
```

### Запуск в режиме разработки

```bash
npm start
```

### Запуск на устройствах

```bash
# Android
npm run android

# iOS
npm run ios

# Web
npm run web
```

## Сборка приложения

### EAS Build

```bash
# Установка EAS CLI
npm install -g @expo/eas-cli

# Сборка для Android
eas build --platform android --profile priview

# Сборка для iOS
eas build --platform ios
```

### Локальная сборка

```bash
# Android
expo run:android

# iOS
expo run:ios
```
