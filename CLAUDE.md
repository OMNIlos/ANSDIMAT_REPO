# АНСДИМАТ — полевой калькулятор гидрогеолога

Мобильное приложение: обработка опытно-фильтрационных работ (откачки,
экспресс-опробования, нагнетания, налив), калькулятор, полевой дневник с
картой и вложениями, карты гидроизогипс (встроенный модуль AnsSurf),
синхронизация через Supabase. Expo SDK 53, React Native 0.79 (новая
архитектура, Hermes), Android / iOS / веб. Минимум — Android 7.0 (API 24),
iOS 15.1: ниже не даёт сам React Native.

## Где что

- `App.tsx`, `navigation/RootNavigator.js` — провайдеры, стек экранов,
  нижнее меню (`components/BottomMenuBar.js`).
- `screens/` — экраны; `screens/calculator/` — вкладки калькулятора,
  общее в `shared.js`; `screens/PumpingTestProcessing/` — журналы ОФР.
- `calc/` — расчёты (чистые функции, покрыты тестами).
- `db/` — expo-sqlite. Схема — массив `MIGRATIONS` в `db/schema.js`,
  версия в `PRAGMA user_version`: новая миграция — только в конец массива.
- `sync/` — обмен с Supabase (`engine.js`, описание таблиц — `tables.js`).
- `share/` — импорт и экспорт журналов `.ansdimat`.
- `assets/anssurf/` — собранный модуль карт гидроизогипс (см. ниже).
- `supabase/migrations/` — серверная схема; `docs/` — сборка, облако.
- `Localization.js` — все тексты (ru, en).

## Команды


Перед коммитом — весь набор тестов зелёный (сейчас ~1226 проходят,

## Как писать код

- Комментарии, тексты интерфейса и сообщения коммитов — по-русски.
  Комментарий объясняет «почему», а не «что»: какую поломку предотвращает.
  У компонентов — шапка JSDoc. Стиль соседнего кода важнее вкуса.
- Тесты — рядом, в `__tests__/`, на react-test-renderer. Асинхронное —
  только `await act(async () => { … })`; `act(() => promise)` без блока
  оставляет незакрытый act и ломает дерево следующего теста. Деревья с
  анимациями размонтировать в конце теста.
- Сначала тест, который падает на старом коде, потом правка.
- `Localization.js`: повторный ключ в объекте молча перетирает верхний —
  перед добавлением ключа искать, нет ли его уже. Запасной язык — ru, поэтому
  забытый en-ключ не виден глазами: проверять по `I18n.translations.en`.
- Числовым полям — `{...NO_AUTOFILL}` из `lib/inputProps.js`.

## Что требует заказчик

- Понижение на графиках растёт вверх (ноль внизу).
- Связанные величины пересчитываются сами (S ↔ a, в котловане μ ↔ a) —
  `useStorageLink` в `screens/calculator/shared.js`.
- Меню калькулятора — два плотных ряда; подписи короткие (360 dp).
- «Выход» из аккаунта — только в «Настройки → Аккаунт», с подтверждением;
  в нижнем меню три пункта.
- «Архив откачек» — в карточке «Создать откачку» на главной.
- Никаких периодов лет у версии: у приложения первая версия.
- Карты гидроизогипс — без настольных функций (растр, подложка и экспорт
  для АНСДИМАТ, загрузка из файла, выгрузка grd/GeoTIFF Z/SHP/DXF).
- Всё, что выглядит иначе, чем заказчик привык в поле, он возвращает.

## Android: ловушки, на которые уже наступили

- Прозрачный `Modal` открывается пустым и невидимым (ловит касания), если на
  экране есть анимация Reanimated. Диалоги — через
  `components/ui/DialogLayer.js` (Portal на Android), не через `Modal`.
- Нативный драйвер Animated: `stop()` + `setValue()` — гонка, точка остановки
  приходит позже и перетирает значение. Поэтому `AppearIn` после появления
  переходит на статичный стиль, а `interpolate` — в `useMemo`.
- При отрисовке от края до края клавиатура не ужимает окно —
  `components/KeyboardInset.js` на каждом экране стека.
- `elevation` рисуется поверх соседей без неё; русских переносов в Android 9
  нет — мягкий перенос `­` в строке перевода.
- `withTransactionAsync` expo-sqlite не исключительна — записи журнала
  ставить в очередь (цепочка промисов), id строки — при создании.
- WebView: скрипт «до загрузки» ненадёжен — критичное через
  `injectedJavaScript` + `onLoadEnd`; Leaflet встроен (`components/leafletAssets.js`).

## Модуль карт гидроизогипс (AnsSurf)

Веб-приложение разработчика заказчика, живёт в WebView. Поставка (два HTML,
`ansdimat-export.js`, `img/`) в репозитории не хранится — по умолчанию
лежит в `../.anssurf-src`. `node tools/build-anssurf.js [каталог]` собирает
из неё `assets/anssurf/*.html` (их коммитим): встраивает скрипт экспорта и
картинки, вырезает Яндекс.Метрику, ставит класс `hydro-desktop` и геттер
`window.__hydroZ`, добавляет скин `tools/anssurf-skin.css` и тексты
`PAGE_TEXT`. Все правила скина — под `html.hydro-desktop`. Скрытое по
просьбе заказчика — в конце скина; поля файлов различаются по `accept`
(общий `input[type=file]` задел бы «Свой грид» на шаге «Изолинии»). Без
поставки страницу не пересобрать — править скин и просить поставку.

## Синхронизация (Supabase)

- Удаление мягкое (`deleted_at`), к отправке — `dirty = 1`.
- `updated_at` ставит сервер триггером. У строки хранится `remote_updated_at`
  — версия сервера, от которой идёт правка (миграция v14): расхождение —
  только если сервер ушёл дальше неё; «Эту» делает серверную версию базой.
- Серверные миграции из `supabase/migrations/` применяет владелец проекта
  (SQL Editor или `npx supabase db push`) — ключей к облаку здесь нет.
- Бесплатный проект засыпает после недели простоя и сам не просыпается.
- `.env` — только `EXPO_PUBLIC_*` (в git не лежит, репозиторий публичный);
  серверные ключи — только в `.env.local`, никогда в коммит.

## Git

- На GitHub ветка по умолчанию — `feat/point-attachments`; рабочая — `main`.
  Держать их равными; force-push нельзя.
- Параллельно работают другие сессии Claude и открывают PR — перед правкой
  `sync/`, `db/schema.js` и миграций делать `git fetch` и смотреть, не
  чинит ли уже кто-то то же самое.

## Нельзя

- Проверять удаление, выход и замену на настоящих журналах: только на
  пробных данных, созданных для проверки.
- Коммитить ключи, пароли, `.env.local`.
